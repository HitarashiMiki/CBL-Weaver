# Handcrafted CBL v2 Reading Lists

A collection of carefully crafted **CBL v2** (JSON) reading lists focused on character arcs and story orders.

Unlike mass-generated lists, every entry here is **handcrafted** - reviewed, ordered, and structured for the best possible matching and reading experience in tools like **Kavita**, Komga, and others that support the CBL format.

### Features
- Native **CBL v2** (JSON) format
- Focused on character arcs and clean reading orders
- Optimized for accurate series/volume/issue matching
- Ready to import into modern comic servers

### Compatibility
- Kavita (full CBL v2 support)
- Komga
- Other software supporting the Comic Reading List JSON standard
